# CVXray mobile app (Expo / React Native)

Native app for Android (and iOS later). The analysis runs on the phone with the same engine,
translations, sample postings and course list as the website — imported from `../src/lib`
through the `@/` alias (`tsconfig.json` for types, `metro.config.js` for the bundler). Only
reading a PDF and fetching a job page call the website's API (`src/api.ts`).

## Run and build

```bash
npm install
npx expo start            # dev server; open on a device or emulator
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease   # APK: android/app/build/outputs/apk/release/
```

`android/` and `ios/` are generated by `expo prebuild` and not committed.
Building needs JDK 17 and the Android SDK (`JAVA_HOME`, `ANDROID_HOME`).

## Structure

- `App.tsx` — language picker, input ↔ report
- `src/InputScreen.tsx` — CV (PDF or text) and job (link, text or sample)
- `src/ResultsScreen.tsx` — score, verdict, skills, where to add them, keywords, courses
- `src/api.ts`, `src/ui.tsx`, `src/theme.ts`
